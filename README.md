# 单词记忆 App（每日外语）

一个纯静态的个人单词记忆应用：不用登录、数据存本地，装到手机主屏当小程序用。

## 三个分类

| 分类 | 内容 | 词量 | 更新方式 |
|---|---|---|---|
| 🇬🇧 英语 | 职场与生活高频词，带「生活→职场」双义记忆提示 | 818 | 每天 22:30 自动加 5 词 |
| 🇯🇵 日语 | 生活与职场常用词，含假名、罗马音、敬语提示 | 935 | 每天 22:30 自动加 5 词 |
| 🎒 小学 | 外研社《英语·新启航》教材词，按单元顺序 | 30 / 229 | 每天 18:30 自动加 3 词 |

## 功能

- **4 种学习模式**：卡片翻转 / 选择题 / 拼写练习 / 例句填空
- **艾宾浩斯记忆曲线**：基于 SM-2 算法自动排复习（1 / 2 / 4 / 7 / 15 / 30 天）
- **双重发音**：有道词典真人发音（需联网），失败自动降级到浏览器 TTS
- **4 套主题**：简洁卡片 / 深色沉浸 / 纸质笔记 / 游戏闯关
- **跨设备同步**：生成同步码，粘贴到另一台设备导入（含全部进度与自定义词）
- **分类记忆**：上次选的分类会记住，刷新不回跳

## 小学分类（给小朋友用）

**教材依据**：外研社《英语（新启航）》一年级起点。成都主城区公立小学 1–2 年级从 2024 年秋季起统一使用这套（四川特供，英式发音，难度较低），三年级转外研社三起点。私立学校多配剑桥 Super Minds / 朗文，不在本分类范围内。

**内容规则**

- 词表在 `kids_curriculum.json`，按教材单元顺序排列：一上 71 词 / 一下 85 词 / 二上 73 词，共 229 词
- 每天固定 **3 个新词** + 最多 3 个到期复习词；当天学完显示「今日全部完成」，第二天自动换下一批
- 发音默认**英式**（与教材一致），详情里可切美式
- 每条词带 `grade`（一上/一下/二上）和 `unit`（如 `Unit 3 Colours`），词汇本里显示年级徽章

**专属互动玩法**（只在小学分类生效）

| 玩法 | 说明 |
|---|---|
| 点字母拼词 | 字母块打乱，点选拼词，点格子可撤回；拼错自动清空重来，不扣分 |
| 音效 | Web Audio 实时合成（无音频文件）：答对上行三音、答错下沉两音、通关小旋律 |
| 连击 | 连对 2 个以上弹出「连对 N 个！🔥」，答错清零 |
| 通关撒花 | 拼对一个撒 18 片纸屑，学完 3 词撒 46 片 + 完成页 |

## 目录结构

```
index.html            单页应用（含全部样式与逻辑）
words.js              词库：EMBEDDED_EN / EMBEDDED_JA / EMBEDDED_KIDS
kids_curriculum.json  小学教材词序表（word / grade / unit）
sw.js                 Service Worker，改前端后记得升 CACHE_NAME
manifest.json         PWA 配置
```

## 添加新词

**自动**：两条定时任务分别维护英语（5 词/天）和小学（3 词/天），小学任务按 `kids_curriculum.json` 顺序取未收录的词。

**手动**：直接改 `words.js` 里对应数组，每条 8 个必填字段：

```js
{
  "word": "hello",
  "phonetic": "/həˈləʊ/",
  "meaning": "int. 你好；喂",
  "example": "Hello! I'm Lily.",
  "example_cn": "你好！我是莉莉。",
  "tip": "记忆提示",
  "date_added": "2026-11-23",
  "lang": "en"          // en | ja | kids
}
```

小学分类的词额外带 `grade` 和 `unit` 两个字段。

改完务必校验：整个 `words.js` 能被 vm 解析、数组内无重复 word、8 个字段都非空。

## 部署

GitHub（`hk124cn/word-memory-app`）→ Cloudflare Pages 自动发布，push 即生效。

改动 `index.html` 或 `words.js` 后，把 `sw.js` 里的 `CACHE_NAME` 版本号 +1，否则装到主屏的旧版本会一直用缓存。

## 数据存储

| localStorage 键 | 内容 |
|---|---|
| `wordapp_v3_en` / `_ja` / `_kids` | 各分类的学习进度与统计 |
| `wordapp_v3_*_added` | 用户手动添加的词 |
| `wordMemory_lang` | 上次选择的分类 |
| `wordMemory_theme` | 主题 |
